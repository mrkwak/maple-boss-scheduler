# ADR-0013: 보스별 모집 파티 (희망 인원 2~6)

- 상태: 승인 (2026-10-08) — 사용자 결정 "B. 모집 파티", "희망 인원은 하나만, 매칭 신청할 때 넣기"

## 배경
- 보스마다 2인으로 갈지 3·4·5인으로 갈지 정해야 한다. 지인들이 각자 편할 때 신청하므로 신청 순서와 상관없이 묶여야 한다.

## 결정
- `courses.party_size`(목표 인원)를 추가한다. 비어 있으면 인원 고정 없음(기존 파티).
- 상태는 저장하지 않고 계산한다 (`lib/party.js`): 모집 중(인원 < 목표) / 시간 미정(다 참, 시간 없음) / 확정.
- 신청 매칭: 보스마다 인원(2~6) 하나를 고르면, 같은 보스·같은 인원으로 모집 중이고 내 다른 캐릭이 없는 파티를
  희망 시간 겹침 순으로 보여주고 1순위를 기본 선택. 없으면 새로 모집(1/N).
- 내 합류로 다 차면 바로 약속 시간을 정한다(모두 되는 시간 추천, "나중에" 가능 → 일정 탭 "시간 미정").
- 일정 탭: 모집 중(빠지기, 이 인원으로 확정 = 목표 인원을 지금 인원으로) → 시간 미정(시간 정하기) → 확정(클리어 체크).
- API(새 파일): `POST /api/courses/[id]/join`, `POST /api/courses/[id]/leave`(마지막이면 삭제), `PATCH /api/courses/[id]/clear`.
- 인원 상한 6은 [가정 — 보스별 실제 최대 인원 미확인, `lib/bosses.js`의 maxParty는 null].

## 대안
- 신청 때 바로 채우기: 먼저 신청한 사람만 묶이고 늦게 온 사람은 남는 사람끼리.
- 전체 자동 편성: 모두 신청할 때까지 기다려야 함.

## 결과
- (+) 신청 순서와 상관없이 같은 인원 원하는 사람끼리 모임
- (−) 같은 보스를 다른 인원으로 고른 사람끼리는 안 묶임(인원을 바꿔 다시 신청하거나 "이 인원으로 확정"으로 조정)
- (−) 동시에 같은 파티 마지막 자리에 합류하면 늦은 쪽이 "이미 다 찬 파티" 오류를 받음(5명 규모라 드묾)
