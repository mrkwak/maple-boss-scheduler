# ADR-0005: 주차 기준은 설정값으로 (기본: 목요일 0시 KST)

- 상태: 제안 — **초기화 시각 미확인**

## 배경
- 로아는 수요일 기준이었다. 메이플 주간 보스는 목요일 0시(KST) 초기화로 알고 있으나, 이번 조사(2026-10-08)에서 공식 출처로 검증하지 못했다.
- 2026-06-18 업데이트에 "일일/주간 컨텐츠 개편" 항목이 있어 규칙이 바뀌었을 가능성도 있다 (세부 내용 미확인).

## 결정
- 주차 계산은 `lib/week.js` 한 곳에서만 하고, 기준 요일·시각·타임존은 상수로 둔다.
  ```js
  export const WEEK_RESET = { weekday: 4 /* Thu */, hour: 0, tz: 'Asia/Seoul' };
  ```
- 모든 주차 데이터는 `week_start`(date)로 저장한다.
- 구현 전 공식 공지로 값을 확인하고 이 ADR을 갱신한다.

- 월간 보스는 별도 기간으로 처리한다 (사용자 결정, 2026-10-08). `lib/week.js`에 `periodOf(date, cycle)`를 두고 `cycle`이 `weekly`면 `2026-W41` 형식, `monthly`면 `2026-10` 형식 키를 돌려준다. 월간 초기화 시각은 [미확인].
- 가능 시간도 주차별로 저장한다 (`availability.week_start`, 사용자 결정 "주마다 시간 정함").

## 결과
- (+) 규칙이 바뀌어도 상수 하나만 수정
- (−) 월간 초기화 시각도 확인 필요
