# ADR-0004: 파티는 '보스 코스(체인)' 단위로 고정

- 상태: 승인

## 배경
- 사용자 선호: 한 캐릭터가 비슷한 보스 여러 개를 **같은 상대 캐릭과 쭉** 간다. 예) 익스 스우 → 노말 흉성 → 노말 카링.
- 로아 프로젝트는 레이드 방 단위로 슬롯을 두고 `group_id`로 3종 세트를 묶었다. 이 경우 방마다 파티를 따로 관리해야 해서 체인 표현이 불편하다.

## 결정
- 1급 개념으로 `Course`를 둔다. `CourseStep`(순서 있는 보스·난이도)과 `CourseMember`(캐릭터)를 각각 Course에 붙인다.
- 파티 구성은 Course에만 있다. Step은 진행 상태(클리어)만 가진다.
- 중간에 한 보스만 다른 멤버로 가야 하면 코스를 나눈다 (예외 구조를 만들지 않음).

## 검증 규칙
- 같은 캐릭터는 같은 주차에 같은 보스를 두 번 배정받지 않는다.
- 같은 사람(member)은 시간이 겹치는 두 코스에 동시에 들어갈 수 없다 (경고).
- 같은 사람의 캐릭터 2개가 한 코스에 들어가는 것: 기본 차단 [사용자 확인 필요].
- 코스 인원 ≤ 코스 내 보스들의 최대 인원 중 최솟값.

## 결과
- (+) "쭉 같이" 요구를 그대로 표현하고, 추천도 코스 단위로 계산하기 쉬움
- (−) 보스별로 멤버가 조금씩 다른 경우 코스를 여러 개 만들어야 함
