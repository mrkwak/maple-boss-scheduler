# ADR-0008: 접근은 비밀 링크로만, 로그인 없음

- 상태: 승인 (2026-10-08, 사용자 결정 "링크 있는 사람만 볼 수 있음")

## 결정
- Discord OAuth 로그인은 넣지 않는다 (ADR-0001의 Discord 로그인 부분 대체).
- URL에 비밀 키를 넣어 공유한다 (예: `https://<앱>/?k=<랜덤 32자>`). Next.js 미들웨어가 환경변수 `ACCESS_KEY`와 비교하고, 맞으면 HttpOnly 쿠키를 발급해 이후 요청은 쿠키로 통과. 틀리면 404.
- 사용자 식별은 "나는 누구?" 멤버 선택 → localStorage 저장. 인증이 아니라 편의 기능이다.
- 링크를 가진 사람은 모두 읽기/쓰기 가능. 코스 멤버 추가는 초대·수락 없이 즉시 확정.
- 검색 엔진 노출 방지: `robots.txt` 전체 차단 + `noindex`.

## 결과
- (+) 가입·OAuth 설정 불필요, 구현 단순
- (−) 누가 수정했는지 신뢰할 수 없음 → 행에 `updated_by`(선택한 멤버 이름)만 기록
- (−) 링크 유출 시 → `ACCESS_KEY` 교체 후 새 링크 공유
