# ADR-0003: 스펙 수집은 배치 + DB 캐시

- 상태: **폐기** (2026-10-08) — maplescouter 자동 수집을 하지 않기로 함 (ADR-0002 개정)

## 폐기 사유
- 이 ADR은 maplescouter 환산값을 GitHub Actions 배치로 수집하는 방식이었다.
- maplescouter 이용약관 제15조가 자동화된 접근을 금지하는 것을 확인해 수집 자체를 하지 않는다.
- 넥슨 Open API 기본정보는 캐릭터 등록·수정 시 서버 라우트로 조회한다. 닉네임·레벨 정기 갱신이 필요해지면 그때 새 ADR로 정한다.

## (기록용) 원래 결정 요약
- GitHub Actions 스케줄 워크플로에서 하루 1~2회, 캐릭터마다 간격을 두고 조회 → DB 캐시, 페이지는 저장값만 표시.
