# ADR-0002: 스펙 데이터 소스 — 환산 주스탯 수동 입력 + 넥슨 Open API

- 상태: 승인 (2026-10-08 개정 — maplescouter 자동 수집 폐기)

## 배경
- 사용자 요구: 캐릭터 비교는 넥슨 API 전투력보다 **maplescouter.com의 환산 주스탯**이 낫다.
- 초안(같은 날)에서는 maplescouter를 배치로 자동 수집하고, "약관에 명시적 금지가 확인되면 재검토"하기로 했다.
- 2026-10-08 세션에서 사이트 접속이 가능해져 확인한 내용:
  - `robots.txt`: `User-agent: * / Allow: /`
  - Cloudflare 사용 (`server: cloudflare`, 대기열 쿠키 `__cfwaitingroom`)
  - **이용약관(2026-07-11 시행) 제15조 금지행위**에 아래가 명시됨 [출처: https://maplescouter.com/ko/agreement]
    - 자동화된 수단(봇·스크립트·크롤러·스크래퍼·헤드리스 브라우저·MCP 등)으로 서비스 또는 API에 접근하는 행위
    - 서비스의 계산·환산 기능을 타 서비스·제품·도구의 백엔드 또는 데이터 소스로 사용하는 행위
    - API 키·토큰·엔드포인트 무단 추출·재사용, 봇 차단 우회, Origin/Referer 위조
  - 제14조: 계산 로직·편집·가공 데이터를 사전 동의 없이 복제·배포 금지
  - 사이트 하단에 "문의하기" 링크와 연락처가 있음 (초안의 "문의 채널 없음"은 틀린 내용)

## 결정
1. **maplescouter 자동 수집(내부 JSON 재현, Playwright 렌더 모두)은 하지 않는다.** 초안의 S1 스파이크는 폐기.
2. 환산 주스탯은 **사용자가 직접 입력**한다 (사용자가 말한 최후 수단).
   - 캐릭터 카드에 maplescouter 결과 페이지 링크(`https://maplescouter.com/ko/info?name=<닉네임>`)만 둔다. 이 앱이 그 페이지를 호출하거나 내용을 읽지 않는다.
   - `spec_value`, `spec_updated_at` 저장, 갱신 시각 항상 표시, 14일+ 지나면 "오래됨" 표시.
3. 기본 정보(닉네임→ocid, 직업, 레벨, 월드)는 **넥슨 Open API**로 가져온다. API 키는 서버 환경변수, 서버 라우트로 프록시.
   - ocid는 닉네임 변경 후에도 유지된다 (사용자 확인) → 캐릭터 식별은 ocid, 닉네임은 표시용으로 주기적 갱신.
4. 스펙 입력 코드는 `SpecProvider` 인터페이스 뒤에 둔다 (현재 구현은 `manual` 하나).
5. 나중에 자동화를 원하면 운영자에게 "문의하기"로 허락을 받은 뒤 이 ADR을 새로 개정한다.

## 대안
- maplescouter 자동 수집 → 약관 제15조 위반. 기각.
- 넥슨 API 전투력만 사용 → 자동이지만 사용자가 원하는 지표가 아님. 참고 지표로 함께 표시할지는 API 응답 확인 후 결정.
- 환산 공식 직접 구현 → 공식 비공개, 직업별 보정 복잡, 제14조 리스크. 기각.

## 결과
- (+) 약관 리스크 없음, 수집 배치·Playwright·Cloudflare 대응 불필요 → 구조 단순
- (−) 사용자가 직접 갱신해야 함 → 입력 동선 최소화(링크 + 숫자 칸 하나)와 오래됨 표시로 보완
- 미결: 사람이 보고 입력하는 것도 제15조 2호("데이터 소스로 사용")로 볼지는 운영자 해석을 모름. 우려되면 문의
