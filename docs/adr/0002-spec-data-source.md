# ADR-0002: 스펙 데이터 소스 — 환산 주스탯(maplescouter) + 넥슨 Open API

- 상태: 승인 (소스·사용 정책) / **수집 방식은 미결 (스파이크 S1)**
- 갱신: 2026-10-08 — 운영자 문의 채널 없음, 허락 없이 사용하기로 사용자 결정

## 배경
- 사용자 요구: 캐릭터 비교는 넥슨 API 전투력보다 **maplescouter.com의 환산 주스탯**이 낫다. 수동 입력은 불편해서 원하지 않는다.
- 조사 결과 (2026-10-08):
  - maplescouter 공식 공개 API 문서: 찾지 못함
  - GitHub `Maplescouter` 조직: 공개 리포 없음, 연락처 `maplescouter@gmail.com` 기재
  - 사이트 하단에 NEXON OPEN API 데이터 기반이라는 문구가 있다는 검색 결과 (직접 확인 못함)
  - **작업 환경 네트워크 정책으로 maplescouter.com 접속이 차단되어 페이지 구조·내부 요청을 직접 확인하지 못함**
  - 이용약관/크롤링 허용 범위: 확인 못함

## 결정
1. 기본 정보(닉네임→ocid, 직업, 레벨, 월드)는 **넥슨 Open API**로 가져온다. API 키는 서버 환경변수, 서버 라우트로 프록시.
2. 환산 주스탯은 **maplescouter를 1차 소스**로 하되, 수집 코드를 `SpecProvider` 인터페이스 뒤에 격리한다.
   ```js
   // fetchSpec(name) => { value, raw, fetchedAt }
   ```
3. 수집 방식은 스파이크 S1에서 아래 순서로 판정한다.
   - (a) 결과 페이지가 호출하는 내부 JSON 요청에 환산값이 있으면 → 서버에서 그 요청 재현 (가벼움)
   - (b) 환산이 브라우저 JS에서 계산되면 → Playwright로 렌더 후 DOM에서 숫자 추출 (무거움, 배치에서만)
   - (c) 둘 다 불가/약관 금지 → 수동 입력 + maplescouter 바로가기 링크로 후퇴
4. **사용 정책 (사용자 결정, 2026-10-08)**: 사이트에 문의할 곳이 없고 이용자가 약 5명이므로 별도 허락 없이 사용한다. 대신 아래를 지킨다.
   - 조회는 배치에서만, 캐릭터당 하루 1~2회 이하, 요청 사이 간격 유지 (ADR-0003)
   - 페이지 열 때 실시간 호출 금지 — 저장값만 표시
   - 화면에 출처(maplescouter.com 결과 페이지 링크) 표시
   - 수집 결과를 외부에 재배포하지 않음 (지인 그룹 내부용)
   - robots.txt/약관에 명시적 금지가 확인되면 이 결정을 재검토
5. 모든 값은 `spec_source`, `spec_updated_at`과 함께 저장하고 UI에 갱신 시각을 항상 표시한다.

## 대안
- 넥슨 API 전투력만 사용 → 공식·안정적이지만 사용자가 원하는 지표가 아님. 보조 정보로만 고려.
- 환산 공식 직접 구현 → 공식이 비공개이고 직업별 보정이 복잡. 기각.

## 결과
- (+) 수집 방식이 바뀌어도 나머지 코드 영향 없음
- (−) 비공식 경로라 사이트 변경 시 깨짐 → 실패 시 이전 값 유지 + 알림
- (−) 약관 리스크는 사용자가 감수하기로 함 → 저빈도·소규모·내부용으로만 운영

## S1 체크리스트
- [ ] maplescouter.com 접근 가능한 환경 확보 (세션 Network access 허용 도메인 추가 또는 로컬 PC)
- [ ] F12 Network(Fetch/XHR)에서 환산값 포함 응답 존재 여부
- [ ] 봇 차단(Cloudflare 등) 여부
- [ ] robots.txt / 이용약관
- [ ] 결과 URL의 `preset` 파라미터 의미 (예: `preset=00000`)
- [ ] 판정 후 이 ADR 상태를 '승인'으로 갱신하고 선택한 방식 기록
