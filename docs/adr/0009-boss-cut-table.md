# ADR-0009: 환산 기준 보스 컷표는 사용자 설정값

- 상태: 제안 (2026-10-08)

## 배경
- 사용자 요구: "환산 6만3천이면 (익스)스우 2인, (익스)세렌 4인" 같은 환산 기준 보스 리스트. 직접 설정하거나 다른 사이트 방식을 참고.
- 벤치마킹 (2026-10-08):
  - maplescouter "파티 보스컷": 파티원 닉네임으로 파티 전체 화력을 계산해 보스별 가능 여부 표시. 시너지·도핑 반영. 자체 계산 → 약관 제14·15조로 사용·복제 불가.
  - 커뮤니티 컷표(인벤, 에펨코리아): "환산 N만 → 보스 목록" 구간표. 예) 익스 스우 2인 약 8만 언급 (2025년 글), 배율 100~110% 기준 구간 정리 (2026-06 글). 작성자·시점·직업·숙련도에 따라 값 차이가 큼.
  - 주간 보스 체크 사이트: 캐릭터별 주간/월간 보스 체크 + 초기화. 컷 판정 기능은 확인 못함.

## 결정
- 컷표는 스프레드시트 `boss_cuts` 탭에 둔다: `boss_id, difficulty, party_size, min_spec, note, source, verified_at`.
  - 사용자가 커뮤니티 자료를 참고해 직접 채우고, 출처와 확인일을 적는다. 배포 없이 수정 가능.
- 판정은 개인 단위 단순 비교: 환산 ≥ `min_spec` 가능 / ≥ 90% 빠듯 [가정] / 그 미만 불가.
- 화면: 캐릭터별 "갈 수 있는 보스" 목록(인원별), 목표 체크 그리드 색상, 코스 내 컷 미달 보스 경고.
- 파티 합산·시너지 계산은 하지 않는다.

## 결과
- (+) 그룹 체감에 맞게 바로 조정 가능, 외부 계산 의존 없음
- (−) 초기값을 사람이 채워야 함, 패치 때마다 갱신 필요 → `verified_at`으로 오래된 값 표시
