# ADR-0009: 헥사 환산·보스 배율(%)로 줄 세우고 파티 묶기

- 상태: 제안 (2026-10-08 개정 — 사용자 요구 "헥사 환산 기준 보스 배율로 캐릭별 줄 세우고 묶기")

## 배경
- 비교 지표는 **헥사 환산**(장비 + 6차 코어 스펙을 합친 환산 [출처: 커뮤니티 가이드, 공식 정의 아님])과, 그 점수 기준 **보스별 배율(%)**.
- maplescouter가 보스별 배율을 보여주지만 계산 공식은 비공개. 운영자에게 사용 허락 문의 중(2026-10-08 메일 작성, 발송은 사용자가 직접).
- 벤치마킹 (2026-10-08):
  - maplescouter "파티 보스컷": 파티원 닉네임으로 파티 전체 화력 기준 보스별 가능 여부 표시 (시너지·도핑 반영)
  - 커뮤니티 컷표(인벤, 에펨코리아): "환산 N만 → 보스 목록" 구간표, 배율 100~110% 기준 정리 등
  - 주간 보스 체크 사이트: 캐릭터별 주간/월간 체크 + 초기화

## 결정
1. 캐릭터마다 `hexa_spec`(헥사 환산)과 `boss_rates`(보스 키 → 배율 %)를 저장한다.
2. 배율 출처 우선순위 (`lib/rates.js`)
   1. 공급자 값 — maplescouter에서 가져온 보스별 배율 (허락 후) 또는 사용자가 옮겨 적은 값
   2. 컷표 환산 — `헥사 환산 ÷ base_spec × 100`. `base_spec`은 시트 `boss_cuts` 탭에 사용자가 정하는 "솔로 100% 기준 헥사 환산"
3. 줄 세우기: 보스 하나를 고르면 그 보스 배율 높은 순으로 캐릭터 정렬 (배율 모르는 캐릭은 뒤).
4. 파티 판정: **파티원 배율 합** ≥ 100% 가능, ≥ 90% 빠듯, 그 미만 불가 [가정 — maplescouter 파티 배율 계산과 다를 수 있음, 실제 값 보고 조정].
   - 예) 헥사 6.3만, 익스 스우 base_spec 12.6만 → 50% → 같은 수준 2명이면 100%
5. 코스 판정: 코스의 모든 보스에 대해 파티 배율을 내고 가장 나쁜 보스 기준으로 표시.
6. 추천(매칭)의 스펙 근접도는 코스 보스들의 배율 비율로 계산 (`lib/matching.js`).

## 기준값 확보 (2026-10-08)
- 사용자가 직접 연 집사0의 maplescouter 효율·보스컷 화면(HTML)을 붙여넣어 줌 → 타일 아이콘 파일명으로 보스 식별, `기준값 = 타일 환산 ÷ (배율/100)` 22개 보스 역산
- 검증: 모든 타일이 `배율 = 그 보스 조건의 헥사환산 ÷ 보스 기준값`으로 맞음. 앱 계산(헥사환산 69,452 기준)과 화면 배율 차이 약 1% 이내 (심볼·포스 손실 S/F 미반영분). 노말 발드릭스는 LV/F 손실이 커서 차이 큼(15.7% vs 22.1%)
- `destiny_*`, `champion_*` 타일은 "데스티니/유챔 확인" 표시용이라 주간 보스 난이도로 넣지 않음 [해석 — 확인 필요]
- **저장 위치**: 저장소가 public이고 약관 제14조(가공 데이터 무단 배포 금지)가 있어 코드에 넣지 않음. 운영은 시트 `boss_cuts` 탭, 개발은 `data/seed.local.json`(깃 제외)

## 결과
- (+) maplescouter 허락 여부와 무관하게 동작 (허락 전엔 컷표 환산)
- (+) 공급자 값이 생기면 자동으로 그 값을 우선 사용
- (−) 파티 배율을 단순 합으로 보는 건 근사치 → 실사용하며 보정
- (−) 컷표 초기값은 사람이 정해야 함
